План работы и иконки в бабблах

Слайды 2, 14–19 из страницы «3_этап_Заводоуковск_ребрендинг 2». В этой версии: без шильдиков в правом углу, текст бабблов в цвет направления, иконки направлений лежат в серой плитке по сетке, слайд 17а выровнен по четырём колонкам плана работы, легенда последнего слайда справа от заголовка с главными иконками.

  • Главные иконки «Инвестиций» и «Молодёжи» временные: варианты Money и Award из набора Icons. Для «Туризма» стоит заглушка, пока иконка рисуется.
  • На слайде 17а вместо фотографий стоят рамки: в файле не нашлось исходных снимков для этих иконок. Фото вставляются при переносе в Figma.
  • Шрифт Actay подхватывается, если он установлен на компьютере (в Chrome). Иначе страница показывает Montserrat: по ширине строки он почти совпадает с Actay.
  • Мастер-иконка «Спорт» в Figma битая, здесь вместо неё гантель из варианта «Sport». Пары одинаковых иконок: «Сельское хозяйство» и «Площадка для роста», «Поддержка инициатив» и «Волонтёры».
